# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any Robben Media repository, please report it responsibly.

**Do not open a public issue.**

Instead, please email security concerns to the repository maintainer or contact us through [robbenmedia.com/contact](https://robbenmedia.com/contact).

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

We will acknowledge receipt within 48 hours and work to address the issue promptly.

## Supported Versions

Security updates are generally provided for the latest version of each project only.
