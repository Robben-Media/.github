# Contributing

Thanks for your interest in contributing to Robben Media projects.

## Getting Started

1. Fork the repository, or branch from `main` if you have write access
2. Create a focused branch
3. Make your changes
4. Run the checks this repository already uses (see its README or CI caller)
5. Commit with a clear message
6. Push and open a pull request

## Code Style

- Follow the existing language and patterns in the repository
- Keep commits atomic and well-described
- Do not add a second ecosystem without changing the repo class

## Pull Requests

- Use the repository pull request template
- Link related issues (`Fixes #n` only when the PR fully resolves it)
- Provide evidence for every claim in the Testing section
- Ensure CI checks pass

## Questions?

Open an issue or reach out at [robbenmedia.com/contact](https://robbenmedia.com/contact).
